### Flight Delay Analysis Dashboard using Power BI & Power Query

In this project, I analyzed a large flight operations dataset to uncover delay patterns, airline performance, airport traffic, and the major factors contributing to flight delays. Using Power Query for data preparation and Power BI for visualization, I built an interactive dashboard that provides meaningful business insights.

**🔹 Dataset: https://www.kaggle.com/datasets/usdot/flight-delays**

**🔹 Project Highlights**
###### Cleaned and transformed the dataset using Power Query
###### Merged Flights, Airlines, and Airports datasets
###### Created an interactive dashboard using Power BI
###### Built DAX measures for key performance indicators
###### Designed dynamic filters and drill-down capabilities for better analysis

**🔍 Key Insights**
###### Departure delays have a strong impact on arrival delays.
###### Weather, airline operations, and late aircraft are the primary causes of delays.
###### Flight distance has little influence on delays but strongly correlates with air time.
###### Delay patterns vary across airlines and months.
###### The interactive dashboard enables users to explore flight performance using filters for airline, airport, month, and day of the week.
